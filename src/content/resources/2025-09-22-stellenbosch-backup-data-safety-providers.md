## Common pitfalls (and the fix)

- **Everything on Desktop** but not in a synced Known Folder → Map **Desktop/Documents** and verify green checkmarks.  
- **Cloud only** (no second copy) → Add **File History/Time Machine** on an external drive.  
- **No restore test** → Recover a dummy file from cloud and from the external drive today.  
- **External drive in same bag** → Store it away from the laptop; theft/water can take both.  
- **Sync conflicts** → Use one **primary** device for edits; review version history before restoring.

## FAQs

**Q: Is a USB flash drive OK for backups?**  
**A:** It’s fragile and easy to lose. Prefer an **external SSD/HDD** plus cloud—two copies on different media.

**Q: Will backups slow my laptop?**  
**A:** Not if configured well. We throttle background sync and exclude giant temp folders.

**Q: Can you prove my backups work?**  
**A:** Yes—our handover includes a **restore test** and a one-page note with where your copies live and how to recover.

**Q: What about privacy?**  
**A:** We use **minimal-access** methods; you can be present. Backup credentials are stored by you; we don’t retain your data.

## Common pitfalls (and the fix)

- **Wrong edition/region** → confirm plan and region before purchase.  
- **MFA roadblocks** → bring the phone with the authenticator; add a backup method.  
- **Licences on the wrong account** → we verify identity and ownership before activation.  
- **Stuck pending updates** → install OS updates first; ensure 15–25 GB free.  
- **“Free” download sites** → avoid. We’ll fetch directly from Microsoft/Adobe.

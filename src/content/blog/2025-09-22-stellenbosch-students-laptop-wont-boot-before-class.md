## Identify the problem (what you’ll see)
- **No power:** no lights/fan at all.  
- **Boot loop:** Windows “Preparing Automatic Repair,” logo → black screen → restart; or macOS stuck at Apple logo/progress bar.  
- **Beeping/clicking:** beeps at startup or ticking from inside the laptop.  
- **Peripheral boot:** system tries to boot from a USB/SD/dock.  
- **After updates:** failed Windows/driver update leads to loops or “Undoing changes.”

## Safe steps (do this in order)
1. **Wall power & brick** — Plug directly into a known-good wall socket; avoid multi-plugs. Confirm charger LED.  
2. **Hard shutdown** — Hold **Power 10–15s** to turn fully off. Wait 5s, then one normal boot.  
3. **Battery reset** — Unplug charger; hold **Power 20–30s**; reconnect and boot. If removable, reseat the battery.  
4. **Remove everything external** — USBs, SD, docks, external drives, HDMI/USB-C displays. Try a clean boot.  
5. **Try recovery (if reachable)**  
   - **Windows:** From Sign-in/Start, hold **Shift** → **Restart** → **Troubleshoot > Startup Repair**.  
   - **macOS (Intel/Apple Silicon):** Hold **Power/Touch ID** until **Options** → **Continue** → Disk Utility/Recovery.  
   If you can’t reach these screens, stop and seek diagnostics.  
6. **Protect your files** — If the drive reads, copy Desktop/Documents to cloud/USB. If not, don’t run risky tools—request **Data Recovery (Simple/Logical)**.  
7. **Plan the fix** — If software corruption is likely, a **Windows Reinstall** (with pre-backup if needed) restores usability quickly. If hardware is suspect, start with **Diagnostics**.

## Do-nots (to avoid data loss)
- **Don’t** keep hard-resetting through **Automatic Repair** loops.  
- **Don’t** run **CHKDSK/First Aid** repeatedly on **clicking** or failing drives.  
- **Don’t** reinstall over your only thesis copy without a backup attempt.  
- **Don’t** flash BIOS/UEFI mid-crisis unless advised.

**Q:** Can you save my thesis if Windows won’t boot?  
**A:** Often, yes. If the drive still reads, we image it and extract Desktop/Documents first, then rebuild Windows. If the drive is failing, we’ll advise the safest next step and lab options.

**Q:** How quickly can I get back to class?  
**A:** Many reinstalls/simple fixes complete the same or next business day, depending on queue and drive health. Expedited starts available when possible.

**Q:** I use OneDrive/Google Drive—do I still need a backup?  
**A:** Versioning helps, but it doesn’t cover everything. We still recommend a quick manual copy of key folders or our backup-first workflow before reinstall.

**Q:** Will you keep my data?  
**A:** By default, we retain recovered data only short-term for handover, then securely delete. Longer retention can be recorded in your job file.
